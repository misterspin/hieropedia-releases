# Hieropedia public release artifacts

This repository stores public preservation files from Hieropedia releases.

Use the [public release index](https://hieropedia.org/data/releases/index.json) to select a release and its exact download locations. Verify the recorded SHA-256 checksums and file sizes before using a downloaded copy. A release records a published state; later corrections do not replace that state silently.

The current public record and its editorial policies are available at [hieropedia.org](https://hieropedia.org/).
